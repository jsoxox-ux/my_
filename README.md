# 규정 도우미

지정한 서버 폴더의 규정을 검색하고 Claude 또는 Gemini로 근거 기반 한국어 답변을 만드는 Streamlit 앱입니다.

## 실행

Python 3.10 이상에서 저장소 디렉터리로 이동한 뒤 실행합니다.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0
```

1. `regulations/`에 규정 파일을 넣거나 앱에서 다른 서버 폴더 경로를 지정합니다. 하위 폴더도 검색합니다.
2. **폴더 읽기 / 새로고침**을 누릅니다. 수정·삭제된 문서는 새로고침 시 반영되며 이전 대화는 지워집니다.
3. Claude 또는 Gemini를 선택하고 해당 제공자의 API 키를 앱에 직접 입력합니다. 계정에서 사용할 수 있는 모델 ID로 수정할 수 있습니다.
4. 질문하면 답변 아래 **검색 근거 확인**에서 원문 발췌와 파일 이름, PDF 페이지를 확인할 수 있습니다.

지원: 텍스트 PDF, DOCX(문단·표), UTF-8/CP949 TXT, Markdown. 파일당 25MB. 이미지·스캔 PDF는 OCR, HWP/HWPX는 PDF/DOCX 변환이 필요합니다. DOCX와 텍스트는 페이지 정보 대신 본문 조각 위치를 표시합니다. 파일은 Git에 올리지 않도록 기본 규정 폴더를 제외했습니다.

## 검색과 개인정보

한국어 문자 2~4그램 TF-IDF로 문서를 검색하고 상위 5개 발췌를 전달하는 로컬 검색 RAG입니다. 별도 임베딩 API 비용은 없으며 의미 기반 임베딩 검색은 아닙니다. 표현이 크게 다른 질문은 규정의 용어로 다시 질문하세요. 검색 점수는 정확도나 법적 신뢰도가 아닙니다. 관련 발췌가 없으면 모델 호출 없이 안내합니다. 질문은 매번 독립적으로 검색하므로 후속 질문에도 주제와 조건을 명시하세요.

API 키는 비밀번호 입력란의 현재 Streamlit 세션에만 보관하며 코드나 파일에 기록하지 않습니다. 질문과 검색된 발췌는 선택한 제공자에게 전송됩니다. 제공자의 데이터 처리 정책과 조직의 규정 반출 허용 범위를 확인하고 사용하세요. 답변의 인용은 모델이 생성하므로 실제 발췌와 대조해야 합니다.

개인 또는 신뢰된 내부 환경용입니다. 인증과 폴더 접근 제어가 없으므로 공개 인터넷에 그대로 배포하지 마세요. 공용 배포 시 인증, 허용 폴더 제한, HTTPS 및 사용자별 접근 제어를 먼저 추가해야 합니다. 기본 실행은 파일을 서버에서 읽는 방식이며 브라우저의 PC 폴더 경로를 직접 읽을 수 없습니다.

## 검증

```bash
python -m pytest -q
```

검색·한국어 문서 추출·DOCX 표·손상 파일 처리·제공자 요청 형식·UI 초기 화면을 검증합니다. API 요청 테스트는 모의 응답을 사용합니다. 실제 모델 응답은 본인의 API 키로 별도 확인해야 하며 사용 요금이 발생할 수 있습니다.

## Vercel 웹 버전

Vercel에서는 `index.html` + `web/`의 브라우저 앱과 `api/chat.js`의 서버리스 API를 사용합니다. 기존 Streamlit 버전은 그대로 보존했습니다.

```bash
npm ci
npm test
npm run build
npx vercel dev  # 로컬에서 API까지 함께 실행
npx vercel --prod
```

Vercel 프로젝트 설정은 Vite, 빌드 명령 `npm run build`, 출력 폴더 `dist`입니다. Node.js 22 이상을 사용하세요. 배포에는 Vercel 계정 인증이 필요합니다.

웹 버전에서는 서버 폴더 경로 대신 브라우저의 **폴더 선택 / 파일 선택**으로 규정을 불러옵니다. PDF·DOCX·TXT·MD를 브라우저에서 추출하고 문자 n-gram TF-IDF로 검색합니다. 파일당 25MB, 전체 100MB, 200개 파일 및 10,000개 발췌 제한이 있습니다. 스캔 PDF는 OCR 처리가 필요합니다. 새 선택은 자료를 교체하며 새로고침하면 자료·키·대화가 사라집니다. 공유 저장소나 영구 업로드 기능은 없습니다.

키와 문서 원본을 디스크/브라우저 저장소에 저장하지 않습니다. 모델 호출 시 사용자가 입력한 키, 질문, 검색된 최대 5개 발췌가 Vercel 서버 함수를 거쳐 선택한 모델 제공자에게 전송됩니다. 서버에 공용 API 키를 설정하지 않으므로 사용자는 각자의 키를 입력합니다. HTML로 문서·답변을 실행하지 않고 텍스트로 표시합니다. 민감한 규정은 조직의 외부 전송 정책을 확인하세요.

`npm test`는 한국어 검색과 두 제공자의 모의 API 요청, 입력 검증 및 오류 정보 비노출을 검사합니다. 실제 모델 응답은 별도 API 키로 확인해야 합니다.
